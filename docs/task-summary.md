# Task Summary

## Objective
Practise Linux user and group administration, log filtering, file permission and ownership controls, and temporary-user management.

## Activities
- Create `forensic01` with a home directory and Bash shell; add it to `sudo`.
- Create a mock system log with at least 20 timestamped events.
- Filter log entries using `grep`, inspect with `less`, `head`, `tail`, and save an error report.
- Create `confidential.txt`, set mode `600`, change ownership to `root`, and observe access as `forensic01`.
- Create `guest1` and `guest2`, add `guest1` to `sudo`, and remove `guest2` including its home directory.

## Deliverables
- `commands_used.txt`
- Genuine terminal screenshots under `evidence/screenshots/`
- Log and analysis report
- Reflection on access permissions and ownership
